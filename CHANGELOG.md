# Changelog

All notable changes to this skill are listed here. Versions follow [semantic versioning](https://semver.org/).

## 1.0.0 — 2026-10-10

First public release, distilled from publishing [Sticky Folders](https://github.com/Tuosang/obsidian-sticky-folders) to the Obsidian community directory.

- Seven-phase pipeline: survey, directory checks, in-app testing, README and images, repository and release, directory submission, after listing.
- Approval gates for every public or personal step: public repository, first push, releases, Developer Policies, *Publish*.
- References: README structure and wording, screenshot and GIF recipes for the real Obsidian app, the community directory submission and every review finding seen so far with its fix.
- Scripts: `obsidian_eval.sh`, `capture.py`, `make_gif.py`, `make_demo_vault.py`, `privacy_scan.py`.
- Assets: release workflow with build-provenance attestations, Obsidian ESLint config, version-bump script, example demo vault.
- Installable as a Claude Code plugin, as a personal skill folder, or as a `.skill` file for Claude.ai.
